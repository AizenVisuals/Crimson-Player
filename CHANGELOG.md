# Changelog

All meaningful updates are tracked here. User-facing versions are shipped through GitHub Releases; a commit on main is **not** automatically a new app version.

## Unreleased

- Professional bilingual README and store metadata drafts.
- Documentation for privacy, security, licensing, streaming feasibility and distribution.
- Release workflow separation between ordinary CI builds and explicit versioned releases.

## v0.2.0 — Android preview

- Light, dark and system themes, Inter typography, compact music screens.
- Animated four-destination bottom navigation with integrated mini-player.
- Display actual audio artwork and honest placeholders.
- Real playback progress control rather than fabricated waveform illustrations.
- Adjusted Android audio permission handling.

## v0.1.0 — Initial Android preview

- Flutter application scaffolding and Media Kit playback engine.
- Android local library, albums, favorites, search and queue.
- Experimental direct HTTPS audio stream playback.
