# Security policy

The latest Android preview receives active fixes; older previews have no guaranteed security maintenance.

Use GitHub's **private vulnerability reporting** feature if available. Otherwise, open a public issue requesting a private contact channel, without publishing sensitive exploit details, files, passwords or access tokens.

Review priorities: audio permissions, untrusted stream URLs, media decoder safety, transitive dependencies, release signing and any future account integrations.

A CI-passing build is **not** a security audit.
